# Dynamic Portfolio Website

## Overview

This project is a responsive portfolio website developed as part of my Front End Development Internship at ApexPlanet. The application demonstrates modern web development concepts including dynamic content rendering, project filtering, form validation, and responsive design using HTML, CSS, and JavaScript.

## Features

### Dynamic Project Gallery

* Displays projects dynamically using JavaScript.
* Filter projects by category (Web, Mobile, All).
* Automatically updates displayed projects without reloading the page.

### Contact Form Validation

* Validates user input before form submission.
* Ensures all required fields are completed.
* Verifies email format correctness.
* Provides user-friendly feedback through alerts.

### Responsive Design

* Mobile-friendly layout using CSS media queries.
* Adaptive project grid for different screen sizes.
* Responsive navigation menu.

### Performance Optimization

* Lazy loading of project images.
* Efficient DOM manipulation.
* Clean and maintainable code structure.

## Functionalities

### Project Filtering

Users can:

* View all projects
* Filter Web projects
* Filter Mobile projects

The gallery updates dynamically based on the selected filter.

### Form Validation

The contact form validates:

* Name field
* Email field
* Message field
* Email format

Successful submissions display a confirmation message.
